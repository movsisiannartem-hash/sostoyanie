# Центр окрашивания и стрижки волос «Состояние» (Краснодар)

Официальный веб-сайт центра эстетического окрашивания и стрижки волос **«Состояние»** (Краснодар, ул. имени Тургенева, д. 133). 

Проект разработан в концепции «тихого люкса» (quiet luxury): благородная тёмная эстетика (`#050507`), утончённая Didone-типографика, деликатные золотистые акценты (`#E8CCB4`), живые фотографии работ и бесшовные переходы.

---

## Особенности и структура сайта

### 1. Главный экран (Hero Section)
- **Типографика**: роскошный антиквенный заголовок **Forum** (Didone) в 3 строчки (*«Эстетика вашего / совершенного / цвета»*) с лёгким весом шрифта.
- **Визуальный образ**: широкоформатный портрет модели с демонстрацией открытого плеча и струящихся локонов.
- **Шёлковое затемнение**: многослойный градиентный dissolve (`mask-image` + overlay), плавно растворяющий нижнюю границу фото в глубокий чёрный цвет без резких линий среза.
- **Интерактивные элементы**:
  - Кнопка быстрой записи через виджет **YClients** (`https://n567509.yclients.com`).
  - Быстрый переход в галерею работ.
  - Анимированная капсула прокрутки (мышь + пульсирующий шеврон).

### 2. Услуги и стоимость (51 реальная процедура)
- Полный каталог услуг салона, разбитый по 8 удобным категориям:
  - *Женские стрижки*
  - *Уход для волос*
  - *Окрашивание волос*
  - *Сложное окрашивание*
  - *Окрашивание корней*
  - *Тонирование волос*
  - *Брови и ресницы*
  - *Укладка волос*
- Интерактивный аккордеон с подробным описанием каждой техники и фиксированными ценами.

### 3. Портфолио работ
- Сетка реальных окрашиваний и стрижек в формате WebP (пропорция 4:5).
- Модальный просмотрщик (Lightbox) с поддержкой полноэкранного зума, переключения стрелками и закрытия по клавише Esc.

### 4. Реальные отзывы гостей (Яндекс Карты)
- 6 подлинных 5-звёздочных отзывов от реальных клиентов салона с Яндекс Карт.
- Бесконечная круговая карусель слайдов с поддержкой свайпа, переключения стрелками `1/6` — `6/6` и индикаторами прогресса.
- Прямая ссылка на профиль организации в Яндекс Картах.

### 5. Контакты и локация
- Интерактивная тёмная Яндекс Карта с точными координатами салона (Тургенева, 133).
- Кнопки копирования в буфер для номера телефона (`+7 (965) 457-41-50`) и точного адреса.
- Прямые ссылки на мессенджеры и соцсети: Telegram, WhatsApp, ВКонтакте.
- График работы: ежедневно с 10:00 до 21:00.

### 6. Правовая база (152-ФЗ РФ)
- 4 автономные юридические страницы, оформленные в едином дизайне:
  - `privacy-policy.html` — Политика конфиденциальности
  - `terms-of-service.html` — Пользовательское соглашение
  - `cookie-policy.html` — Политика использования файлов cookie
  - `personal-data-consent.html` — Согласие на обработку персональных данных
- Интерактивный баннер согласия с файлами cookie с модальным окном детальной настройки категорий.

### 7. Брендинг и фавиконы
- Сгенерированный пакет иконок для всех устройств: `favicon.ico`, `favicon-32x32.png`, `favicon-16x16.png`, `apple-touch-icon.png`, `favicon.svg`.

## Стек технологий

- **HTML5**: Семантическая разметка, Schema.org Microdata, OpenGraph и Twitter Cards мета-теги.
- **CSS3**: CSS Custom Properties (Design Tokens), Flexbox, CSS Grid, аппаратные анимации, медиа-запросы для всех разрешений (от 320px до 4K).

## Локальный запуск

Сайт полностью статичен и не требует дополнительных сборок:

```bash
# Клонировать репозиторий
git clone https://github.com/movsisiannartem-hash/sostoyanie.git

# Перейти в каталог
cd sostoyanie

# Запустить локальный сервер
python3 -m http.server 8000
```

После этого откройте в браузере: `http://localhost:8000`.

## Развёртывание (Deployment)

### GitHub Pages:
1. Перейдите в **Settings** репозитория на GitHub.
2. В левом меню выберите **Pages**.
3. В разделе **Build and deployment** укажите:
   - Source: `Deploy from a branch`
   - Branch: `main`, папка `/ (root)`
4. Нажмите **Save**. Сайт будет доступен по адресу `https://movsisiannartem-hash.github.io/sostoyanie/`.

### Vercel / Netlify:
Просто импортируйте репозиторий `movsisiannartem-hash/sostoyanie` в панель Vercel или Netlify. Проект определится автоматически как статический сайт (Zero Config).
